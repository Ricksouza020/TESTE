# DIRETRIZES DO PROJETO TESTE

## 1. Regras Operacionais e Idioma
- Todo o raciocínio, linha de pensamento e comunicação devem ser estritamente em Português do Brasil (pt-BR).
- O projeto segue rigorosamente o Protocolo Global de Execução (`GLOBAL_AI_EXECUTION_PROTOCOL.md`).

## 2. Skills do Projeto
- Este projeto possui seu próprio isolamento de habilidades na pasta `.agents/skills/`.
- Cada nova skill deve atender a uma demanda especializada e recorrente deste projeto (meta de 3 a 5 skills por projeto).

## 3. Fluxo de Trabalho
- GitHub é a fonte de verdade operacional.
- Tarefas chegam via GitHub Issues (`[AGENT TASK]`).
- Execução sequencial com validação antes do fechamento de cada Issue.
